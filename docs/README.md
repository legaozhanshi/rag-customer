# 文档索引

这是 RAG 智能客服系统的设计与工程规范入口。

推荐阅读顺序：

1. [project-conventions.md](project-conventions.md)：代码、配置、错误处理和安全约束。
2. [architecture.md](architecture.md)：目录结构、模块职责、依赖方向和数据流。
3. [api.md](api.md)：应用服务、检索工具、模型 Gateway 和流式事件契约。
4. [testing.md](testing.md)：测试层级、替身和验收要求。
5. [development-plan.md](development-plan.md)：按依赖顺序实施功能。
6. [decisions/](decisions/)：查看重要架构决策及其取舍。

架构与接口文档描述目标行为；实现行为发生变化时，应在同一变更中更新相关文档。
